# Fix Profile Avatar Not Showing in Navigation Header

## Context
The navigation header's profile dropdown always shows a letter initial instead of the user's actual profile picture, even when the user has uploaded one. The session data (`auth.user`) contains `profile_picture` (set on login in `AuthService.php:57`), but the navbar never reads it.

## Root Cause
`app/Views/layouts/navbar.php:223` hardcodes the avatar as a letter initial:
```php
<span class="inline-flex h-8 w-8 items-center justify-center rounded-full bg-brand-100 ..."><?php echo $profileInitial; ?></span>
```
It never calls `profile_image_url()` or `initials_avatar_data_uri()`.

Other views (marketplace, show, settings) already use the correct pattern — see `profile/settings.php:9-11`.

## Fix: `app/Views/layouts/navbar.php`

**Step 1** — After line 14 (`$profileInitial = ...`), compute the profile image URL:
```php
$profileImageRaw = profile_image_url((string) ($user['profile_picture'] ?? ''));
$profileFallback = initials_avatar_data_uri($displayName);
$profileImageUrl = $profileImageRaw !== '' ? $profileImageRaw : $profileFallback;
```

**Step 2** — Replace the avatar `<span>` at line 223 with an `<img>` tag:
```php
<img
    src="<?php echo e($profileImageUrl); ?>"
    alt="<?php echo e($displayName); ?>"
    class="h-8 w-8 rounded-full border-2 border-neutral-200 bg-neutral-200 object-cover"
    data-fallback-src="<?php echo e($profileFallback); ?>"
    onerror="this.onerror=null;this.src=this.getAttribute('data-fallback-src');"
>
```

This uses the same `onerror` fallback pattern already used in marketplace.php and show.php.

## Files to Modify
- `app/Views/layouts/navbar.php` — lines 14 area + line 223

## Verification
1. Log in as a user **with** a profile picture → navbar should show the picture
2. Log in as a user **without** a profile picture → navbar should show initials SVG avatar
3. Break the image URL (e.g. point to a missing file) → onerror should fall back to initials
4. Check mobile drawer — no avatar there currently, so no change needed
